QA Locators

Every element the testers need has a custom attribute qa-test="...". Use it instead of ids, XPath or text. 89 static locators + dynamic ones below.

Rule: CSS selector = [qa-test='value']. Keep the value exactly as written (lowercase, hyphens).
// Java + Selenium
driver.findElement(By.cssSelector("[qa-test='login-identifier']")).sendKeys("nour@mail.com");
driver.findElement(By.cssSelector("[qa-test='login-password']")).sendKeys("Strong@123");
driver.findElement(By.cssSelector("[qa-test='login-submit']")).click();

// dynamic locator (account number inside the attribute)
String balance = driver.findElement(By.cssSelector("[qa-test='account-balance-1000000001']")).getText();

// all history rows
List<WebElement> rows = driver.findElements(By.cssSelector("[qa-test='history-row']"));

// Page Object style
private final By loginSubmit = By.cssSelector("[qa-test='login-submit']");
